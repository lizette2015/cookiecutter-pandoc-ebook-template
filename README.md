

## Usage

    $ pip install cookiecutter
    $ cookiecutter https://github.com/lizette2015/cookiecutter-pandoc-ebook-template.git

## Makefile

Al editar este archivo, usar TABS en vez de SPACES, de otra forma el comando **make** arroja error ``"makefile:16: *** missing separator.  Stop."``



Use Calibre Viewer to check if fonts and css styles are displayed properly (Sumatra only shows some of these configurations)
